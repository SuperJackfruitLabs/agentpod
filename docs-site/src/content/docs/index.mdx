<CardGrid stagger>
  <Card title="Attach, don't migrate" icon="puzzle">
    Point AgentPod at agent runtimes you already run. It detects them in place — Claude
    Code, Codex, OpenCode, Hermes, OpenClaw and Pi — rather than asking you to move
    anything.
  </Card>
  <Card title="Reaches machines you can't" icon="random">
    Every node dials *out* to the hub over a WebSocket. No inbound ports, no port
    forwarding, and laptops behind NAT or CGNAT work the same as a VPS.
  </Card>
  <Card title="Files, logs, terminal, health" icon="laptop">
    Read a workspace, tail a log, open a shell, check what's running, plan a cleanup —
    on any station in the fleet, from one place.
  </Card>
  <Card title="Self-hostable" icon="setting">
    The hub is a Bun service with a Postgres database. The console is a static site. You
    run all of it.
  </Card>
