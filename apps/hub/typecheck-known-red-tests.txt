# This is the same mechanism as `typecheck-known-red.txt`, pointed at the half
# of this app the compiler had never seen. `tsconfig.json` includes only
# `src/**/*`, so no test file was ever typechecked and no workflow ran `tsc`
# at all — which is how `capabilities: ["health", "config.manage"]`, a genuine
# type error against `Capability[]`, sat in six test files across three merged
# PRs while every suite stayed green. The capability was missing from the
# contract's enum, the compiler would have said so in all six places, and
# nothing asked it.
#
# The 224 errors below are NOT that bug. They are pre-existing strict-null
# noise — `possibly undefined`, `string | undefined` — and fixing them is a

# `capabilities: ["health", "not-a-real-capability"]` lands in a file with a

#
